# Story Map Pusat SMART Desa Negeri Selangor

Mock-up static site. Upload `index.html` to the root of the GitHub repository.

## GitHub Pages
Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save.

Selepas deployment, GitHub Pages akan menyediakan pautan `https://geospatialpms-glitch.github.io/STORY-MAP-PUSAT-SMART-DESA-NEGERI-SELANGOR/`.

Nota: kandungan lokasi/koordinat dalam mock-up perlu diganti dengan data rasmi sebelum digunakan sebagai laman rasmi.
